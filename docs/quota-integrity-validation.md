# 额度、任务与统计修复验收

本次修复落实审查会话的四批行为要求，保留现有本地增量监控、SSH 权限和只读 SQLite 边界。

- 额度：官方优先；历史记录按事件时间排序，15 分钟和重置边界过滤；账户/目录隔离；历史与失败不冒充成功、不触发提醒。
- 刷新：额度独立提交，忙时有界追加；stdout/stderr 消费有界，握手错误和 EOF 及时结束；SQLite 有超时；统一目录与实际二进制诊断。
- 任务：主看板接入事件监控，归档不代表执行成功；无活动只代表未知；发现或读取失败降级，恢复后回到 ready；SSH 参数结构化保留。
- 统计：JSON 空白兼容，每日事件增量，时区统一，显示覆盖率；追加日志检查点缓存；不再分摊工具费用；安装包记录提交 SHA。

## 回归入口

`make test-data-integrity` 构建后执行 store 回归、两平台共享额度 fixtures 和隔离 SQLite/JSONL/app-server 集成回归。共享 fixtures 位于 `tests/fixtures/codex-rate-limits.json`，Windows SelfTest 读取同一文件。

集成回归覆盖官方 89% 与历史 99%、候选事件排序、查询失败、初始化错误、EOF、stderr 大量输出、百万历史 token 与今日 100 token、追加日志不重复计数、日志缺失覆盖、历史过期、同尺寸同时间文件替换、握手后进程退出。领域自测覆盖账户/目录切换、身份未知、TTL、重置、完成未归档和时区缓存；1.5 秒慢统计下额度提前提交，10 次忙时点击仅追加一次查询，全量统计完成不回滚额度。

## 边界

本地额度扫描仍限制 24 个候选文件、每文件末尾 512 KiB；未观察到的事件不能推断为当前账户状态。等待批准/等待输入没有可靠事件时保持未知。执行结束仅表示轮次结束，仍需检查成果。

SSH 的进程文本不保留引号，`-F` 只支持可明确重建的绝对 ASCII 路径；不明确的参数降级，保留既有证据。Windows 额度实现和共享回归已补齐，本机未安装 .NET，需 Windows CI 验证编译及实际运行。macOS 产物为本机 ad-hoc 构建，尚未安装或发布。
